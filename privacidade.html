Política de Privacidade

maquina-videos · válida a partir de 19 de novembro de 2026

1. Quem usa o aplicativo

O maquina-videos é uma ferramenta de uso próprio. Só o seu autor, e as contas Google que ele mesmo autoriza, usam o aplicativo. Ele não é distribuído nem oferecido ao público.

2. Dados acessados

Com a sua autorização, por meio dos Serviços de API do YouTube, o aplicativo acessa somente:

  • o canal do YouTube que você escolher na tela de autorização do Google (nome, identificador e configurações do canal);
  • os vídeos enviados por meio do aplicativo (título, descrição, visibilidade e miniatura);
  • as estatísticas desses vídeos e do canal (visualizações, curtidas, comentários, tempo assistido), pelo YouTube Analytics.

3. Como os dados são usados

Os dados servem apenas para enviar e atualizar os vídeos do próprio usuário e para gerar relatórios internos de desempenho. Não são usados para publicidade, não são vendidos e não são usados para treinar modelos de inteligência artificial.

4. Armazenamento e segurança

As credenciais de acesso (tokens OAuth) e os relatórios ficam guardados apenas no computador do autor, em arquivos locais. Nada é enviado para servidores do aplicativo, porque ele não possui servidores.

5. Compartilhamento

Os dados obtidos pelas APIs do Google não são compartilhados com terceiros nem transferidos a ninguém.

6. Retenção e exclusão

Os tokens ficam guardados enquanto a autorização estiver ativa. Você pode revogar o acesso a qualquer momento em myaccount.google.com/permissions; ao revogar, o aplicativo deixa de ter acesso e os tokens locais são apagados. Para pedir a exclusão de relatórios, use o contato abaixo.

7. Serviços de API do YouTube

O aplicativo usa os Serviços de API do YouTube. Ao usá-lo, você também concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
