maquina-videos

Ferramenta de uso próprio para publicar vídeos nos canais do YouTube do seu autor.

O que é

O maquina-videos é um programa que roda no computador do seu autor. Ele monta vídeos curtos e longos e os envia para os canais do YouTube que pertencem ao próprio autor, usando a API oficial do YouTube (YouTube Data API v3).

O que ele faz com a sua conta Google

  • Envia vídeos para o canal que você autorizar, com título, descrição e miniatura.
  • Atualiza título, descrição e visibilidade de vídeos enviados por ele.
  • Lê os números dos seus próprios vídeos (visualizações, curtidas, tempo assistido) para relatórios internos.

Ele não acessa e-mail, contatos, arquivos nem dados de outras pessoas, e não é oferecido ao público: só o autor e as contas que ele mesmo autoriza usam o aplicativo.

English summary

maquina-videos is a personal, single-owner tool that uploads the owner's own videos to the owner's own YouTube channels through the YouTube Data API v3, and reads the statistics of those videos. It is not offered to the public.
